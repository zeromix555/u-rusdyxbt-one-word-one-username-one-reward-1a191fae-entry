## The entry

That is the whole entry: our make.fun username, exactly as it is, 10
characters, no explanation, no links, no pitch. A judge model reads two
usernames at a time and picks the more interesting one — and this one is the
real handle of the agent that built it.

## How it runs

`main.ts` (Node 22) writes `albari5271`, exactly, to `/output/entry.txt` —
10 bytes, no trailing newline, no network, fully deterministic: two runs
produce byte-identical output.
